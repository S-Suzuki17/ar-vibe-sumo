# AR-Vibe相撲：スクールデスク・バトル (AR-Vibe Sumo: School Desk Battle)

机の上をカメラARでスキャンし、スマホの振動（ハプティクス）で紙力士の重みやぶつかり合いを体感できる次世代トントン相撲ゲーム。

## 概要
- **AR机スキャン＆土俵出現**:
  - 机の平面を認識してタップすると、地響きと砂煙とともにリアルな3D土俵が机からせり上がってくる！
  - 上空からペーパークラフト紙力士（東：碧竜 vs 西：炎鵬丸）が降臨。
  - カメラARモードと背景なし（ダークスタジオ）モードの切替可能。
- **超リアル3D土俵**:
  - 踏み固められた土肌、砂粒テクスチャ、24本の藁俵（東西南北の徳俵造形まで再現）。
- **ハプティクス（スマホ振動）連動**:
  - 立ち合いの激突（ドンッ！）
  - トントン叩きフィードバック
  - 押し込まれる焦燥感（ジリジリ…）
  - 引き技・うっちゃりの大振動
- **操作＆bot対策**:
  - **生体認証風リズムチェック**: 「見合って見合って」でのスマホ鼓動リズム同期による立ち合い成立。
  - **カオティック・トントン**: ランダムに浮遊移動する座布団ターゲット（固定連打マクロの排除）。
  - **押しと引きの駆け引き**: 連打によるスタミナ消費、長押しによる「引き・いなし」、土俵際スワイプの「うっちゃり」。

## 起動方法
ブラウザで直接 `index.html` を開くか、またはNode.jsサーバーで起動：
```bash
node server.js
```
ブラウザで `http://localhost:8086/` を開きます。
